# 사박: 코렐리안 스파이크 온라인

3~6명이 실시간으로 함께하는 코렐리안 스파이크(Corellian Spike) 사박 웹게임. Node.js + WebSocket 기반, 서버가 게임 상태를 관리하는 구조(다른 플레이어 손패는 공개 전까지 서버 밖으로 전송하지 않음).

## 실행

```bash
cd sabacc
npm install
npm start          # http://localhost:3000
npm test           # 룰 엔진 테스트
```

환경 변수: `PORT` (기본 3000), `TURN_SECONDS` (턴 제한시간, 기본 60초).

외부 친구와 플레이하려면 Render·Fly.io·Railway 등 WebSocket을 지원하는 Node 호스팅에 배포 후 초대 링크 공유.

## 기능

- 방 만들기 / 4자리 코드·초대 링크로 참가 (3~6명), 방장이 시작 크레딧 설정(10~500)
- 핸드마다 참가비 → 2장 배분 → 3라운드 × (드로우 → 베팅 → 스파이크 주사위) → 쇼다운
- 드로우 5종: Buy Draw · Buy Face-Up · SWAP Draw · SWAP Face-Up · Stand
- 베팅: 체크·베팅·콜·레이즈·폴드 (사이드 팟 없이 진행하도록 라운드 한도 = 남은 인원 최소 보유 크레딧)
- 스파이크 주사위 같은 문양 → 사박 시프트(전원 손패 교체)
- 핸드 팟 / 사박 팟(합계 0 승자만 획득, 아니면 이월), 동률 시 싱글 블라인드 드로우
- 새로고침·재접속 시 자리 복구, 오프라인·시간 초과 시 자동 행동(스탠드·체크, 콜이 필요하면 폴드)
- 채팅, 게임 로그, 룰 요약, 모바일 대응

## 규칙 구현 (src/rules.js)

| 항목 | 내용 | 근거 |
|---|---|---|
| 덱 | 62장: 원·사각·삼각 × (+1~+10, −1~−10) + 사일롭 2장 | cgstation 룰북 카드 갤러리 |
| 진행 | 3라운드, 라운드마다 드로우 → 베팅 → 스파이크 | cgstation 룰북 목차 |
| 참가비 | 핸드 팟 2 + 사박 팟 1 | 공개 코렐리안 스파이크 규칙 |
| 족보 | 퓨어 사박 > 풀 사박 > 플릿 > 이-하 > 라일렛 > 스쿼드런 > 지 위즈 > 스트레이트 카이론 > 밴서스 와일드 > 룰 오브 투 > 사박 > 널렉 | 공개 코렐리안 스파이크 규칙 |
| 드로우 비용 | Buy 1크레딧, SWAP·Stand 무료 | **가정** |
| 최대 손패 | 5장 | **가정** |
| 시작 크레딧 | 50 | **가정** |

**가정** 항목은 룰북 원문 확인 후 `src/rules.js` 상수만 바꾸면 반영됨.
