# Kessel Sabacc 온라인

3~6명이 실시간으로 함께하는 Kessel Sabacc 웹게임. Node.js + WebSocket 기반, 서버가 게임 상태를 관리하는 구조(다른 플레이어 손패는 공개 전까지 서버 밖으로 전송하지 않음).

## 실행

```bash
cd sabacc
npm install
npm start          # http://localhost:3000
npm test           # 룰 엔진 테스트
```

환경 변수: `PORT` (기본 3000), `TURN_SECONDS` (턴 제한시간, 기본 60초).

같은 네트워크의 친구는 `http://<내 IP>:3000`, 외부 친구와 하려면 Render·Fly.io·Railway 등 Node 호스팅에 배포(웹소켓 지원 필요) 후 초대 링크 공유.

## 기능

- 방 만들기 / 4자리 코드·초대 링크로 참가 (3~6명), 방장이 시작 칩 설정(2~20)
- 턴 진행: 스탠드 또는 1칩 드로우 (샌드/블러드 덱·버림 더미 4곳) 후 1장 버림
- 3턴 뒤 공개, 임포스터 주사위 선택, 자동 정산·탈락 처리, 최종 승자 판정·재경기
- 새로고침·재접속 시 자리 복구, 오프라인·시간 초과 플레이어 자동 행동(스탠드)
- 채팅, 게임 로그, 룰 요약 모달, 모바일 대응

## 규칙 구현 (src/rules.js)

| 항목 | 내용 |
|---|---|
| 덱 | 샌드·블러드 각 22장: 1~6 × 3장, 임포스터 3장, 사일롭 1장 |
| 라운드 | 3턴, 드로우 비용 1칩 |
| 족보 | 퓨어 사박(사일롭 2장) > 사박 1/1 … 6/6 > 차이 작은 순 (동률 시 합이 작은 쪽) |
| 사일롭 | 다른 카드 값과 동일 |
| 임포스터 | 공개 시 주사위 2개 중 하나 선택 |
| 정산 | 승자(동점 전원) 베팅 회수 / 패자 베팅 손실 + 벌금(사박 1칩, 아니면 차이만큼) |
| 종료 | 칩 0 → 탈락, 1명 남으면 종료 |

규칙 수치는 `src/rules.js` 상수로 분리되어 있어 하우스 룰에 맞춰 수정 가능.
