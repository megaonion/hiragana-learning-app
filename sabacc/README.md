# 사박: 코렐리안 스파이크 온라인

3~6명이 실시간으로 함께하는 코렐리안 스파이크(Corellian Spike) 사박 웹게임. Node.js + WebSocket 기반, 서버가 게임 상태를 관리하는 구조(다른 플레이어 손패는 공개 전까지 서버 밖으로 전송하지 않음).

## 실행

```bash
cd sabacc
npm install
npm start          # http://localhost:3000
npm test           # 룰 엔진 테스트
```

환경 변수: `PORT` (기본 3000), `TURN_SECONDS` (턴 제한시간, 기본 60초).

외부 친구와 플레이하려면 Render·Fly.io·Railway 등 WebSocket을 지원하는 Node 호스팅에 배포 후 초대 링크 공유.

## 기능

- 방 만들기 / 4자리 코드·초대 링크로 참가 (3~6명), 방장이 시작 크레딧 설정(10~500)
- 게임마다 참가비 → 2장 배분 → 3라운드 × (드로우 → 베팅 → 스파이크 주사위) → 쇼다운
- 드로우 5종: Buy Draw(1) · Buy Face-Up(2) · SWAP Draw · SWAP Face-Up · Stand, 공개 카드는 가져가면 자동 보충
- 베팅: 레이즈(2 이상)·콜·스탠드·폴드, 올인 시 사이드 팟 정산
- 스파이크 주사위 같은 문양 → 사박 시프트(전원 손패 교체)
- 게임 팟 / 사박 팟(합계 0 승자만 획득, 아니면 이월), 동률 시 싱글 블라인드 드로우
- 새로고침·재접속 시 자리 복구, 오프라인·시간 초과 시 자동 행동(스탠드, 레이즈가 걸려 있으면 폴드)
- 채팅, 게임 로그, 룰 요약, 모바일 대응

## 규칙 구현 (src/rules.js, src/game.js)

| 항목 | 내용 | 근거 |
|---|---|---|
| 덱 | 62장: 원·사각·삼각 × (+1~+10, −1~−10) + 사일롭 2장 | 룰북 카드 갤러리 |
| 진행 | 3라운드, 라운드마다 드로우 → 베팅 → 스파이크. 모든 단계는 딜러 왼쪽부터, 라운드마다 딜러 왼쪽으로 이동 | 룰북 |
| 스파이크 | 같은 기호면 모두 손패를 버리고 같은 장수만큼 새로 받음 | 룰북 |
| 드로우 | Buy Draw 1크레딧, Buy Face-Up 2크레딧, SWAP은 먼저 버리고 교환, 공개 카드 자동 보충 | 룰북 |
| 베팅 | 레이즈 2 이상, 콜, 스탠드(첫 순서·올인), 폴드(낸 크레딧은 팟에 남음) | 룰북 |
| 족보 | 퓨어 사박 > 풀 사박 > 플릿 > 이-하 > 라일렛 > 스쿼드런 > 지 위즈 > 스트레이트 카이론 > 밴서스 와일드 > 룰 오브 투 > 사박 > 널렉 | 룰북 족보 페이지 카드 예시 + 공개 규칙 |
| 승패 | 널렉은 0에 가까울수록 → 카드 수 → 양수 우선. 완전 동점이면 다른 값이 나올 때까지 한 장씩 뽑기. 널렉 승리 = 게임 팟, 사박 승리 = 게임 팟 + 사박 팟 | 룰북 '게임 승패' |
| 준비 | 참가비 게임 팟 2 + 사박 팟 1, 2장씩 배분, 공개 카드 1장, 버린 카드 더미 별도 | 룰북 '게임 준비' |
| 사이드 팟 | 올인 시 베팅 금액 기준으로 분할 (참가비·드로우 비용은 메인 팟) | **가정** |
| 최대 손패 | 5장 | **가정** |
| 시작 크레딧 | 50 | **가정** |

**가정** 항목은 룰북 원문 확인 후 `src/rules.js` 상수만 바꾸면 반영됨.
