    로그

      채팅

        코렐리안 스파이크 룰 요약

        구성

        • 카드 62장: 원·사각·삼각 3개 스테이브 × (초록 +1~+10, 빨강 −1~−10) + 사일롭(0) 2장
        • 스파이크 주사위 2개, 크레딧 칩(1·5·10)

        목표

        손패 합계를 0에 가깝게. 정확히 0이면 사박.

        진행

        • 게임 시작 시 참가비: 게임 팟 + 사박 팟 . 2장씩 받고, 공개 카드 1장을 펼칩니다.
        • 3라운드 동안 매 라운드 드로우 → 베팅 → 스파이크 순서로 진행합니다. 모든 단계는 딜러 왼쪽부터, 라운드가 끝나면 딜러 왼쪽 참가자가 다음 딜러가 됩니다.
        • 드로우(한 가지 선택)
          • ① Buy Draw: 크레딧 내고 드로우 더미 맨 위 카드 1장
          • ② Buy Face-Up: 크레딧 내고 공개 카드 1장
          • ③ SWAP Draw: 손패 1장을 먼저 버리고 드로우 더미 맨 위 카드와 교환
          • ④ SWAP Face-Up: 손패 1장을 먼저 버리고 공개 카드와 교환
          • ⑤ Stand: 그대로 유지
          공개 카드를 가져가면 드로우 더미에서 한 장을 채웁니다. 손패는 최대 장.
        • 베팅: 레이즈(크레딧 이상) · 콜 · 스탠드(추가 베팅 없음, 첫 순서이거나 올인일 때) · 폴드(이미 낸 크레딧은 팟에 남고 다음 게임에 다시 참여). 올인 시 사이드 팟으로 정산.
        • 스파이크: 주사위 2개가 같은 문양이면 사박 시프트, 모두 손패를 버리고 같은 장수만큼 새로 받습니다.

        족보 (강한 순)

        1. 퓨어 사박 사일롭 2장
        2. 풀 사박 +10 +10 −10 −10 + 사일롭
        3. 플릿 포카드 + 사일롭
        4. 이-하 페어 + 사일롭
        5. 라일렛 트리플 + 페어
        6. 스쿼드런 포카드
        7. 지 위즈 ±10과 반대 부호 1·2·3·4
        8. 스트레이트 카이론 연속된 4개 숫자
        9. 밴서스 와일드 트리플
        10. 룰 오브 투 투 페어
        11. 사박 그 밖의 합계 0
        12. 널렉 합계가 0이 아님: 0에 가까울수록 → 카드 수가 많을수록 → 양수가 음수보다 우선

        사일롭·널렉 제외 족보는 합계 0일 때만 인정. 숫자 비교는 부호 무관(+5와 −5는 같은 숫자). 사박 동률은 카드 수 → 양수 합 → 가장 높은 양수 카드 순. 족보를 모두 따져도 같으면 동점자끼리 서로 다른 값이 나올 때까지 한 장씩 뽑아 승부(싱글 블라인드 드로우).

        정산

        • 최고 족보가 게임 팟 획득. 합계 0이면 사박 팟까지 획득, 아니면 사박 팟은 다음 게임으로 이월.
        • 한 명 빼고 모두 폴드하면 남은 사람이 게임 팟 획득.
        • 다음 게임 참가비를 낼 수 없으면 탈락, 마지막 1명이 최종 승자.
